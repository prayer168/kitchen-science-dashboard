# 設計規格

## 對象與目的

以國小中高年級自然科學為主要使用情境，讓學生透過點擊、滑桿、顏色變化、生活案例與闖關題目建立廚房科學概念。

## 資訊架構

1. 認識廚房裡的材料：14 張材料卡。
2. 物質能溶解的量：5 種物質、溫度與加入量滑桿。
3. 菜汁變色了：5 種待測液、pH 色帶與檢定步驟。
4. 生活小應用：6 張可操作的現象卡。
5. 挑戰小測驗：12 題、四選一、即時解說與分數。
6. 自主學習的影音或資料：語音朗讀與 6 個外部資源。

## 互動與無障礙

- 按鈕均使用原生 button 或 anchor 元素。
- 測驗作答後鎖定選項並顯示正確答案。
- 生活應用按鈕提供 `aria-pressed` 狀態。
- 語音使用瀏覽器 SpeechSynthesis，語系設定為 `zh-TW`。
- 支援 `prefers-reduced-motion`，降低動畫需求使用者的動態效果。
- 外部連結以新視窗開啟，並使用 `noopener noreferrer`。
