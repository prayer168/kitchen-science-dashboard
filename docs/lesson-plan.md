# 教學活動建議

## 學習目標

學生能：

1. 描述常見廚房材料的狀態、溶解、混合與受熱特性。
2. 分辨溶解速度與最大溶解量不是完全相同的概念。
3. 使用紫高麗菜汁的顏色初步判斷酸性、中性與鹼性。
4. 用科學概念解釋烘焙膨發、乳化、糊化、凝固、褐變及冰鹽降溫。

## 建議流程（40 分鐘）

1. 導入（5 分鐘）：請學生說出家中廚房常見材料。
2. 材料觀察（8 分鐘）：分組選 3 張材料卡，比較能否溶於水與遇熱變化。
3. 溶解模擬（7 分鐘）：固定加入量，改變溫度並記錄觀察。
4. 指示劑探索（8 分鐘）：依檢定步驟預測並操作 5 種待測液。
5. 生活應用（5 分鐘）：每組選一個現象，用「我觀察到／我認為因為」說明。
6. 闖關與統整（7 分鐘）：完成 12 題測驗，針對錯題回到前頁查證。

## 安全提醒

實作時需由成人或教師陪同。不品嚐實驗材料，不混合不明清潔劑；熱水、刀具與刺激性液體需由成人操作。
