# 廚房中的科學｜互動視覺學習儀表板

這是一個可直接部署到 GitHub Pages 的互動式自然科學教材。

## 主題內容
- 認識 14 種廚房材料與科學特性
- 模擬 5 種物質在不同水溫與加入量下的溶解情形
- 操作紫高麗菜汁天然指示劑，學習檢定酸鹼性
- 探索 6 個可操作的生活小應用
- 完成 12 題即時回饋挑戰
- 使用語音朗讀與 6 個已檢查的自主學習連結

## 使用方式
1. 下載本資料夾或 zip。
2. 上傳到 GitHub repository 根目錄。
3. 在 GitHub Pages 啟用部署。

## 教材文件

- `docs/design-spec.md`：介面與互動設計
- `docs/lesson-plan.md`：教學活動建議
- `docs/references.md`：參考資料與連結
- `docs/test-report.md`：功能與連結測試紀錄
